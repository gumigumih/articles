# AIとわたしの深夜エンタメ会議 通常回テンプレート

通常回は、第1部「AI分野最新情報」と第2部「テーマ特集」で構成する。共通の執筆・成果物ルールは`article.md`、リサーチと運用は`monetization.md`、共通の受け渡しは`AGENTS/common/writing-workflow.md`を正本とする。

## 通常回の構成

### 第1部：AI分野最新情報（無料）

- AI×エンタメのニュース・新サービスを3〜6件扱う。
- 各項目は「見出し」「客観的な要約」「公式または信頼できるURL」「事業・UX・技術・権利のいずれかに触れる軽い見立て1〜2文」で構成する。
- 第1部だけで、何が起きたかと今回の観察が分かるようにする。
- X投稿を使う場合は、利用者報告・反応・公式デモを区別し、仕様や導入実績の根拠にしない。

### 第1部末尾：テーマの予告

- 第2部のテーマ、比較事例、読者と一緒に考える問いを短く予告する。
- 有料区切りの前に、テーマに対応する会社で使える分析スライドが付くこと、メンバーシップでは読み放題、個別購入も可能であることを自然に案内する。
- 次のコメントを入れる。

```md
<!-- ここから有料エリア（note投稿時にこの位置で「続きを読むには」の区切りを設定） -->
```

### 第2部：テーマ特集（有料）

- 第1部のニュースを再要約せず、複数事例を中心仮説・比較軸・暫定判断で掘り下げる。
- 見出しはテーマ固有の問いや結論を表す。固定の「開発会社ウォッチ」「評価視点1」「評価視点2」は使わない。
- 事業性、UX、技術、権利、安全性、対象年齢、運用、収益などから必要な論点を選ぶ。
- 根拠のないリスク、企業評価、価格比較は書かない。仮説・未確認事項・架空例は関連する説明の近くで区別する。
- 太字の一言判定や調査側の作業メモを置かない。判断は理由の流れで伝える。
- 特集回は1件を中心にしてよいが、無料部の事例紹介を繰り返すだけにしない。

## 記事の終わり方

- まとめでは、今回の問いを振り返り、マガジンへの軽い導線を置く。
- 次号予告は書かない。
- 参考リンクは末尾にまとめる。
- 図解、スライド、PDF／PPTXの生成・添付・案内は`article.md`に従う。

## 文体

- です・ます調を基調に、一人称は「私」または「ぐみ」。
- 深夜のひとりごとのような親しさを保ちつつ、事実説明は落ち着いて書く。
- 一文に複数の内容を詰め込まない。60字前後を目安に、長くなれば分ける。
- 煽り表現、一般論だけの結論、同じ言い回しの反復を避ける。

## カバー画像プロンプト

カバー画像の生成自体は手動で行う。記事下書きと同時に、`note/{記事スラッグ}.cover-prompt.md`へ下記の型を実際の号数・日付・タイトルで保存する。本文へは入れない。

カバーはシリーズ共通の固定フォーマットを使う。記事内容に合わせてニュース、サービス、キャラクター、画面UIなどのモチーフを毎回追加・変更しない。差し替えるのは号数・日付・記事タイトルと、必要な場合の定型サブコピーだけにする。

```text
添付した画像と同じスタイルで、note有料記事のカバー画像を作成してください。

【マガジン名】
AIとわたしの深夜エンタメ会議

【号数】
{{issue_number}}

【日付】
{{date}}

【タイトル】
{{topic_title}}

【サブコピー】
{{fixed_subcopy}}

【サイズ】
1280 × 670 px

【スタイル】
・タイトルは筆文字のような太い手書き風
・濃紺〜紫の夜空、星、右上の三日月
・白、イエロー、青緑、ピンクをアクセントに使う
・下部に光る折れ線を置く
・小さく表示してもタイトルが読める構成
・シリーズ共通のレイアウト、背景、装飾、文字組みを維持する
・記事内容固有のイラスト、サービス名を連想させるUI、ニュースごとの図解は追加しない

【NG】
・小さい文字を多く入れる
・情報を詰め込みすぎる
・煽り表現や広告バナー風のデザイン
```

## X投稿文の下書き

- 本文・カバープロンプトとは別に、`note/{記事スラッグ}.x-post.md`へ2案を作る。
- 公開済みURLを確認できるまで`{{note記事URL}}`を残す。Xへの実投稿はしない。
- 数字を煽りに使わず、URLを除いて200字前後を目安にする。

```text
【案A】
『{{topic_title}}』
AIとわたしの深夜エンタメ会議 #{{issue_number}}を更新しました。

無料エリアでは{{news_count}}件のAI×エンタメニュースを紹介し、有料エリアではテーマ特集を掘り下げています。

{{note記事URL}}

#AIとわたしの深夜エンタメ会議
```

```text
【案B】
{{topic_title}}を、事業・UX・運用の目線で考えました。

{{note記事URL}}

#AIとわたしの深夜エンタメ会議 #{{issue_number}}
```

## 提示前チェック

- 第1部と第2部の役割が分かれている。
- 第2部が比較・判断のあるテーマ特集になっている。
- 事実、URL、数値、責任主体、仮説・未確認事項の区別が保たれている。
- カバープロンプトとX投稿案は本文と別ファイルになっている。
- 次号予告、作業メモ、無根拠な断定、冗長なニュース再要約がない。

## 文章化依頼テンプレート

```text
以下の候補一覧とテーマメモを、第1部「AI分野最新情報」＋第2部「テーマ特集」の形式で記事にしてください。

【候補一覧】
{{news_items}}

【テーマメモ】
{{theme_memo}}

【必須条件】
- 候補一覧とテーマメモ以外の事実、URL、分析を足さない。
- 第1部はニュースの無料ダイジェストと各1〜2文の軽い見立てにする。
- 第2部は複数事例を比較するテーマ特集にし、第1部の要約を繰り返さない。
- 事実、分析、仮説、未確認事項、架空例を区別する。
- テーマ本文の確定後、対応スライドと本文用図解を作る前提で、比較軸と結論を明確に書く。
- です・ます調で、深夜のひとりごとのような親しさを保つ。
```

# AIとわたしの深夜エンタメ会議：スライドテーマ

## 目的

記事のおまけスライドを、マガジンのカバーと同じ「深夜のエンタメ会議」らしい見た目で揃える。読みやすさを最優先にし、テーマ色は情報の役割を見分けるために使う。

## 色

| 役割 | 色 | 使い方 |
| --- | --- | --- |
| 夜空 | `#071337` | 表紙・最終ページ・表見出し |
| 文字 | `#0C1B45` | 明るい背景での本文・見出し |
| 紙面 | `#F8F7FC` | 本文ページの背景 |
| 星の金 | `#F8CE67` | 重要な結論、区切り、QRまわり |
| 会話の青緑 | `#007B91` | 明るい紙面で使う共通要素、DMM側、補助線。本文色として十分なコントラストを確保する |
| ピンク | `#F1779E` | 比較相手、仮説・注目点 |
| 紫 | `#7056BA` | 補助的な強調。水色・ピンクと併用しすぎない |
| 補足 | `#66718E` | 出典、注記、ページ番号 |

## レイアウト

- 本文ページは明るい紙面に濃い文字を置き、表の見出しだけ夜空色にする。
- 青緑とピンクは、比較する二者や流れの違いを示すときだけに使う。同じ対象には全ページで同じ色を使う。
- 金は結論、URL、最終ページの導線に限定する。装飾目的で多用しない。
- 表紙と最終ページは夜空を使い、本文ページは高いコントラストを保つ。
- 図解は関係を説明するために使い、カードや飾りを増やさない。出典・留保は本文に近い位置へ短く置く。
- 表紙・まとめ・最終ページを除く各スライドに、比較表、フロー、関係図、判断マップ、工程図のいずれかを最低1点入れる。文章を要約しただけの箱や、全ページ同じ飾りの繰り返しは図解とみなさない。図だけで理解できない箇所には説明を添え、口頭補足を前提にしない。
- テーマ事例スライドは、事例の違いに合わせて図解の役割を変える。枚数を6枚へ固定しない。例：判断の分岐、音声制作の工程、データから解説への流れ、IP権利の関係、端末内処理の境界、公演運用の移設フロー。
- 表紙はタイトル・補足・余白を中心にする。内容のまとめと、お礼・メンバーシップ案内は別ページにし、締めのデザイン変更で結論を失わない。

## 書体

- `M PLUS 1p`を基本書体にする。本文はRegular、注記はMedium、見出し・結論はBold以上を使う。
- 太字の強調だけに頼らず、文字サイズと余白でも優先度を示す。

## 最終ページ

- 作者名「ぐみ」と、メンバーシップのURLを必ず明記する。
- QRコードはURLと併記し、QRを読めない環境でも到達できるようにする。
- カバー画像を使う場合は最終ページなど一度に留め、縦横比を保って全体が見えるように配置する。文字とQRは画像の内容を隠さない位置へ分け、コントラストを確保する。

## noteへの配布

- noteではPDFを標準の添付ファイルにする。読者の端末やフォント環境が違っても、紙面とQRが同じように表示されることを優先する。
- PPTXは、読者が社内資料として編集・再利用できること自体に価値がある場合だけ、任意の追加ファイルとして添付する。
- PDFとPPTXを併記する場合も、note上の案内ではPDFを読むための本体、PPTXを編集用と明記する。

# 共通ルール

全媒体の記事で必要になるルールです。媒体別の入口を読んだあと、記事の作業に必要なファイルだけを追加で読みます。

| 目的 | ルール |
| --- | --- |
| 調査・文章化の役割分担、本文と付属ファイルの境界 | `AGENTS/common/writing-workflow.md` |
| 見出し、Markdown、Git運用 | `AGENTS/common/structure.md` |
| 事実、出所、公開前の品質確認 | `AGENTS/common/quality.md` |
| 文体の共通部分 | `AGENTS/common/style.md` |
| 画像・図解 | `AGENTS/common/image.md` |
| リンク・参考資料 | `AGENTS/common/link.md` |

## 読み方

1. ルートの`AGENTS.md`と`AGENTS/README.md`を読む。
2. `AGENTS/platforms/README.md`から対象媒体の入口を選ぶ。
3. 媒体入口が指定する共通ルールだけを読む。
4. 記事種別に専用ルールがあれば、最後にそれを読む。

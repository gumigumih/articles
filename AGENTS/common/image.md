# 画像・図解ルール

- 記事ごとに専用の画像ディレクトリを作成
- カバー画像を用意した場合は、記事Markdownのタイトル直前（フロントマター直後）に相対パスで `![CoverImage](images/<記事スラッグ>/cover.png)` を記載
- ファイル名は分かりやすい命名規則を使用
- 画像の説明文を必ず記載
- スクリーンショットは最新のものを使用
- 図解は分かりやすく作成

# 画像・図解ルール

- 記事ごとに専用の画像ディレクトリを作成
- カバー画像を用意した場合は、記事Markdownのタイトル直前（フロントマター直後）に相対パスで `![CoverImage](images/<記事スラッグ>/cover.png)` を記載
- ファイル名は分かりやすい命名規則を使用
- 画像の説明文を必ず記載
- スクリーンショットは最新のものを使用
- 図解は分かりやすく作成
- ファイルサイズを適切に管理

## note記事カバーの既定プロンプト

一般note記事のカバーを依頼されたときの出発点とする。記事ごとのタイトルと主題を入れ、`note/<記事スラッグ>.cover-prompt.md`に保存する。画像生成は別途明示依頼がある場合だけ行う。ユーザーが別のデザインや参照画像を指定した場合は、その指示を優先する。

```text
横長のnote記事カバーを新規作成してください。参照画像は使わず、この記事の内容に合ったデザインにします。

記事タイトル：{{記事タイトルを正確に記載}}
記事の主題：{{内容に合う小さな図形・アイコンの案}}

文字が主役の雑誌風デザイン。タイトルを最前面に、画像全体の大部分を使う大きな太字で配置し、一覧の小さな表示でも読めるようにします。重要な語や数字を強調し、意味がつながる位置で改行してください。文字を省略・追加せず、端で切らないでください。

黒を基調に、白・マゼンタの文字と、シアン・黄色のアクセントを使います。力強い斜めの構図、控えめな紙の質感を加えます。装飾は記事の主題に合う小さなアイコンや幾何学模様に絞り、文字を隠さないようにします。

人物・キャラクター・顔・動物・ロボットは描かず、架空の画面にも入れません。極小の点描、密集した穴状の模様や過度なざらつきは避け、ドットを使う場合は大きめで間隔のある規則的なグラデーションにします。連載名・号数・日付・ロゴ・透かしなど、タイトル以外の文字は入れません。ただしタイトル中の数字は正確に残してください。
```

生成後はタイトルの誤字・欠落、文字切れ、縮小表示での可読性、意図しない人物・キャラクター、ドットの密度を目視確認する。既存画像は確認前に上書きしない。

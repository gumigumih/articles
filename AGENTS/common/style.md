# 文体ルール

## 共通の特徴
- 媒体の読者に合わせた、読み手に届くトーンにする
- 読者への語りかけや共感は、媒体別ルールの範囲で取り入れる
- 「です・ます調」を基本とし、媒体固有の許容範囲を優先する
- 専門用語は丁寧に説明し、初心者にも配慮
- 体験談やストーリー部分は、出所を明確にして感情や気づきを表現
- 技術解説部分は簡潔かつ論理的に
- 適度に改行し、読みやすさを重視
- 絵文字や顔文字は、媒体別ルールで許可される場合だけ適度に使用する

# リンク・参考資料ルール

- 関連記事へのリンクを適切に設置
- 参考資料は信頼できる情報源を使用
- 外部リンクは新しいタブで開く設定（可能な場合）
- 参考資料や引用元は明記

## note埋め込み

- noteで埋め込み表示にしたいURLは、次の専用記法で囲む。本文をnoteへ移すときは、囲みを除去し、URLをnoteの埋め込みとして挿入する。

      <!-- note:embed -->
      https://x.com/example/status/123
      <!-- /note:embed -->

- 通常リンク、参考リンク、本文中のテキストリンクにはこの記法を使わない。
- 埋め込みに対応しないURLは、通常リンクとして残す。

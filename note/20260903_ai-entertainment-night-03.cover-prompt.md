# カバー画像用ChatGPTプロンプト

```text
添付した画像と同じスタイルで、note有料記事のカバー画像を作成してください。

【マガジン名】
AIとわたしの深夜エンタメ会議

【号数】
#3

【日付】
2026.09.03

【タイトル】
ローカルAIとLLMの現在地、創作の裏側を覗く夜

【サイズ】
1280 × 670 px

【スタイル参考(添付画像より)】
・タイトルは筆文字っぽい、勢いのある手書き風の太い文字
・背景は濃紺〜紫の夜空、小さな星を散りばめる
・右上に三日月
・タイトルの近くに「…」「♡」などの吹き出しをアクセントとして配置
・下部に、点を結んだ折れ線(株価チャートのような)ラインを光る線で描く
・配色はネイビーの背景に、白・イエロー(マガジン名部分)・青緑(アクセント)・ピンク(アクセント)
・号数バッジのすぐ近くに、日付を小さく添える(例:「#3 / 2026.09.03」のように並べる)。ジャンルを示す別バッジ(「AI×エンタメ」等)は入れない(マガジン名が既にジャンルを表しているため二重表示にしない)

【目的】
noteの一覧画面で小さく表示されたときでも、タイトルが一瞬で読めてクリックされるデザインにする。有料記事なので、安っぽく見えず「ちゃんと中身がありそう」という信頼感も出す。

【NG】
・小さい文字を多く入れる
・情報を詰め込みすぎる
・「今すぐ稼げる」のような煽り表現
・派手すぎる広告バナー風
```

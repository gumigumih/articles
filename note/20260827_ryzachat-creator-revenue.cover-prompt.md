# カバー画像プロンプト

共通のデザインと生成条件は [note記事カバーの既定プロンプト](../AGENTS/common/image.md) を使用する。参照画像は使わず、画像生成は明示依頼時のみ行う。

- 記事タイトル：ライザと話すお金が、作り手にも戻る？ クリエイターへの還元を掲げるAIの仕組み
- 主題に合わせた装飾：会話・ペン・マイクを示す小さなアイコン
- 現在のローカルカバー：`images/20260827_ryzachat-creator-revenue/cover-selected.png`

共通プロンプトのタイトルと主題に上記を入れ、文字の誤字・欠落やキャラクターの混入を確認する。既存カバーは上書きしない。

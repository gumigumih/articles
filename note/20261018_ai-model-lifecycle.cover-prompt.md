# カバー画像プロンプト

横長のnote記事カバーを新規作成してください。参照画像は使わず、この記事の内容に合ったデザインにします。

記事タイトル：新モデルより、使っているAIの「終わり」が気になる
記事の主題：AIモデルの提供開始・終了・移行期限を、公式情報から収集し、NotionのニュースDBとモデル一覧で追跡する。小さな図形として、モデルのライフサイクルを示す細いタイムライン、終点を示すマーカー、Notionのデータベースを思わせる整然とした行列、公式情報を示す書類の輪郭を使う。

文字が主役の雑誌風デザイン。タイトルを最前面に、画像全体の大部分を使う大きな太字で配置し、一覧の小さな表示でも読めるようにします。重要な語「終わり」を強調し、意味がつながる位置で改行してください。文字を省略・追加せず、端で切らないでください。

黒を基調に、白・マゼンタの文字と、シアン・黄色のアクセントを使います。力強い斜めの構図、控えめな紙の質感を加えます。装飾は記事の主題に合う小さなアイコンや幾何学模様に絞り、文字を隠さないようにします。

人物・キャラクター・顔・動物・ロボットは描かず、架空の画面にも入れません。極小の点描、密集した穴状の模様や過度なざらつきは避け、ドットを使う場合は大きめで間隔のある規則的なグラデーションにします。連載名・号数・日付・ロゴ・透かしなど、タイトル以外の文字は入れません。ただしタイトル中の記号と括弧は正確に残してください。

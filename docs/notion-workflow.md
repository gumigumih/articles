# 旧Notion執筆ワークフロー（廃止）

2026-10-30に、Notion起点の改善・承認・Markdownへの逆同期を廃止しました。
現在は [Notionへの記事バックアップ](notion-backup.md) を使います。

Macの受付とログイン時起動は停止済みです。専用CLI・受付サーバー・SDK依存は撤去しました。
Notionの起動リンクは空の数式へ変更し、旧操作欄は一覧と記事の通常表示から隠しています。
状態・承認・最新レビュー等の既存値、Notion記事、レビュー履歴、ローカル原稿は保持しています。

.notion-workflow/ のSQLite・原稿スナップショット・受付記録・停止済み設定は非公開の旧履歴として残します。
旧依頼の再処理、承認、同期、常駐受付の再起動は行いません。
